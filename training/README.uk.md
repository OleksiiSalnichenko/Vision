# Власні класи: як навчити модель бачити ручку і квіти

Інструкція для тебе: що робиш ти, і в якому порядку. Команди, які запускає
агент, тут не розписані — повна технічна версія англійською лежить поруч,
у [README.md](README.md).

Мережа потрібна лише в чотирьох місцях: встановлення пакетів, встановлення
Label Studio, заливка на Kaggle і саме навчання на Kaggle. Жодна заливка не
відбувається без твого «так».

## Підготовка (один раз)

1. Зареєструйся на https://www.kaggle.com — це безкоштовно.
2. Підтверди номер телефону: **Settings → Phone verification**. Без цього
   Kaggle не дасть GPU.
3. Створи ключ: **Settings → API → Create New Token**. Завантажиться файл
   `kaggle.json` — поклади його в `C:\Users\<твій користувач>\.kaggle\kaggle.json`.
   Агентові ключ не надсилай і не показуй: він перевіряє лише, що файл є.
4. Скажи агентові свій логін Kaggle — він впише його в `training/training.yaml`.
5. Скажи «так» на встановлення інструмента `kaggle` у venv проєкту.

## Зйомка

Модель вчиться рівно тієї сцени, яку їй показали, тому знімай те, що бачитиме камера.

- **Реальні умови**: твій стіл, твоє світло (і денне, і лампа), та сама
  відстань і висота, що в камери. Найкраще знімати самою вебкамерою;
  телефон теж підходить.
- **Ручка дрібна.** Знімай її не лише зблизька, а й здалеку — такою, якою
  вона буде в кадрі камери.
- **Різноманітність**: кілька різних ручок і квітів; лежать, стоять, у руці,
  частково закриті, з різних боків.
- **Кадри без ручки і без квітів**: порожній стіл, олівець, маркер, телефон.
  Вони вчать модель, що ручкою *не є*. Без них вона «бачитиме» ручку всюди.
- Разом приблизно **10 хвилин відео**, кількома кліпами. Назви кліпів прості:
  `desk1.mp4`, `desk2.mp4`.

Віддаєш агентові шляхи до відео — він розріже їх на кадри (кожен 20-й,
приблизно 900 штук) у `data\training\frames\`.

## Готові датасети (за бажанням)

Кілька сотень уже розмічених чужих фото додають різноманітності. Вони можуть
бути не більше п'ятої частини набору — основа завжди твої кадри.
Конкретні датасети з посиланнями й ліцензіями — у розділі 3 [README.md](README.md).
Скачай потрібний у форматі **YOLOv8** і скажи агентові, куди розпакував.

## Розмітка в Label Studio

Агент встановлює Label Studio з твого «так». Запускаєш його ти:

```
venv\Scripts\python training\label_studio.py start
```

Відкриється http://localhost:8080. Програма працює лише на твоєму ноутбуці,
кадри нікуди не йдуть. Зупинити — Ctrl+C у вікні терміналу.

1. Зареєструйся (локальний акаунт, зберігається на цьому комп'ютері), **Create Project**.
2. **Labeling Setup → Custom template → Code** — встав текст, який дасть
   агент (команда `label_studio.py config`). **Save**.
3. **Settings → Cloud Storage → Add Source Storage**, тип **Local files**,
   шлях до теки одного кліпу, наприклад
   `D:\Projects\Vision\data\training\frames\desk1`. Постав галочку
   **Treat every bucket object as a source file** → **Add Storage** →
   **Sync Storage**. Одне сховище на кожен кліп.
4. На кожному кадрі обведи прямокутником кожну ручку і кожну квітку — щільно
   по краях. Кадр, де їх немає, — просто **Submit** без рамок.
5. **Export → YOLO**, збережи zip у `data\training\exports\`.

Кроки в Label Studio написані за документацією. Якщо на екрані щось інакше —
скажи агентові, і він виправить інструкцію.

### Як заощадити час (за бажанням)

1. Розміть спочатку лише ~50 кадрів, експортуй як `first50.zip`.
2. Агент навчить на них грубу модель (з твого «так» на заливку), і вона сама
   намалює рамки на решті кадрів у файл `data\training\tasks.json`.
3. У Label Studio відфільтруй **Annotations = 0**, виділи все,
   **Actions → Delete tasks** (видаляються лише завдання, не картинки).
4. **Import** файлу `data\training\tasks.json`.
5. Пройди кадри: виправ або видали хибні рамки, додай пропущені, **Submit**.
6. Експортуй усе як `data\training\exports\all.zip`.

## Далі робить агент

Кожна заливка і кожен запуск на Kaggle — лише з твого «так».

1. Збирає датасет. Люди, телефони та інші знайомі об'єкти на твоїх кадрах
   розмічаються поточною моделлю, щоб нова модель їх не забула.
2. Заливає датасет на Kaggle (приватно) і запускає навчання на GPU.
3. Забирає готову модель і порівнює її зі старою на твоїх кадрах: як бачить
   ручку, квіти й старі 80 класів, скільки секунд іде на кадр.
4. Якщо ручку видно погано, пропонує варіанти: зняти ближче, більший розмір
   кадру (`imgsz: 960`) або більшу модель `yolo26s`.
5. Конвертує модель в OpenVINO і з твого «так» міняє один рядок у
   `config.yaml` та додає `pen` і `flower` у список класів.

## Перевіряєш ти

Запусти застосунок або камеру — тепер вони бачать ручку й квіти поруч із
людьми, телефонами тощо.

Повернутися на стару модель — той самий рядок у `config.yaml`
(`weights: models/yolo26n_openvino_model`) і прибрати `pen`/`flower` зі
списку класів. Стара модель нікуди не дівається.

## Якщо щось не так

| Що бачиш | Що робити |
|---|---|
| `no Kaggle API key at ...` | створи ключ (Підготовка, крок 3) і поклади файл туди |
| `set training.kaggle.username ...` | скажи агентові свій логін Kaggle |
| `the export has classes not in training.classes: ...` | назва мітки в Label Studio не `pen`/`flower`; виправ і експортуй знову |
| `the export has no pen or flower box at all` | в експорті лише порожні кадри — спершу розміть об'єкти |
| `warning: negatives are below ...` | додай кадри сцени без ручки і квітів |
| Навчання на Kaggle падає без GPU | телефон на акаунті не підтверджено |
